# SCImago Journal Rank (SJR) Offline Searchable Example

This folder contains a practical, real-world example generated using this tool: an offline, lightning-fast searchable interface for over 30,000 academic journals based on the SCImago Journal Rank (SJR) 2025 dataset.

## 📄 Data Attribution & License Note
> **Data source:** SCImago Journal Rank (SJR) ([scimagojr.com](https://www.scimagojr.com/)). 
> This is a free, non-commercial offline search interface developed for academic purposes. The raw bibliographic data belongs to its respective copyright holders (SCImago & Scopus/Elsevier).

---

## 🚀 How to Use This Example
1. Download or clone this repository.
2. Navigate to the `example/` folder.
3. Double-click the generated HTML file (e.g., `scimagojr2025.html`) to open it instantly in any modern web browser (Chrome, Firefox, Edge, etc.)—**no internet connection or Excel required!**
